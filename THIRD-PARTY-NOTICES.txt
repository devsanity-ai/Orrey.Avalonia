Orrery — Third-Party Notices
============================

This library contains code derived from the following third-party projects.


-------------------------------------------------------------------------------
d3-force
-------------------------------------------------------------------------------
https://github.com/d3/d3-force

Orrery's force simulation is a C# port of d3-force. The velocity Verlet
integrator, the alpha cooling model, the fx/fy pinning semantics, the
phyllotaxis node seeding, the seeded linear congruential generator, and the
link / many-body / collide / center / positioning forces all follow the d3-force
algorithms and default constants.
